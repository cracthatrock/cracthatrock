## Featured project: ForgeCore

[**ForgeCore**](https://github.com/cracthatrock/ForgeCore) is my public portfolio project: a configurable Discord bot with a connected web dashboard.

![ForgeCore support dashboard](https://raw.githubusercontent.com/cracthatrock/ForgeCore/main/docs/media/support-desk.png)

- Customizable ticket panels, optional intake forms, claim/close/reopen actions, and transcript archives.
- Welcome templates and configurable basic join roles.
- A command studio for replies, embeds, link buttons, role restrictions, and cooldowns.
- Discord OAuth login, per-server settings, and extension controls.
- Strict TypeScript, SQLite persistence, documented setup, and automated checks.

[Browse the feature gallery](https://github.com/cracthatrock/ForgeCore/blob/main/docs/SHOWCASE.md). The screenshot uses example data in the actual dashboard UI.
