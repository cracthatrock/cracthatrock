# Hi, I'm Crac 👋

I build custom Discord bots, dashboards, and integrations with TypeScript and Node.js. I like making tools that are easy to configure, understand, and maintain.

## Custom development

Available for small commissions and larger bot projects, including:

- Ticket systems, intake forms, support workflows, and transcript archives.
- Welcome messages, role automation, and custom slash commands.
- Web dashboards with Discord login and server settings.
- API integrations, setup, documentation, and ongoing maintenance.

Have a project in mind? [Open a project inquiry](https://github.com/cracthatrock/cracthatrock/issues/new?title=Project%20inquiry) with what you need, your budget, and your preferred timeline. Keep passwords, tokens, and private information out of public issues.
